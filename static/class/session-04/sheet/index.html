Two bakeries stand on the same street in your city. Same flour, same ovens, same hours, the same bread at the same price. Customers buy from whichever one is closer. Bakery A wants to win. Picture a street you know well: who walks past at six in the morning, at noon, in the evening?

Better
The same bread and service as Bakery B, done better (operational effectiveness).
Different
A different customer, a different promise, or the same thing done in a different way (strategic position).

Task 2 · The copy test 8 minutes

1. For each idea: could Bakery B copy it next week, word for word? Write C (copy) or N (no) in the last column.
2. Your best “different” idea. What would Bakery A have to stop doing to make it work? That is the trade-off.
